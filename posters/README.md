## Poster Requirements

All posters were created according to hackathon guidelines:
- Format: PDF or PNG/JPG

- Content: Project overview, methodology, results, and team information
- Templates: Provided in `/templates/` directory

## Download Instructions

To download all available posters along with the winner repositories:

```bash
# Clone the main repository with submodules
git clone --recurse-submodules https://github.com/holistic-ai/hackathon-2025.git
cd hackathon-2025/posters

# All available poster files are in this directory
ls -lh
```

## Notes

- **CloudFront URLs**: These are permanent CDN links hosted by Devpost and remain accessible.
- **GitHub URLs**: Posters embedded in team repositories remain accessible as long as repositories are public.
- **S3 Signed URLs**: These use AWS S3 signed URLs with time-limited access tokens. URLs typically expire after 24-72 hours.
- **Recovery**: Teams can be contacted directly to obtain fresh poster files if needed.
